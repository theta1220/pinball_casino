# pinball_casino の制作で得た知見

対象例: C:/Users/nkcta/pinball_casino。原画座標941×1672。これらはプロジェクト固有で、別ゲームの要件ではない。

- 元画像を図形で隠す実装から、空背景と透過素材の合成へ変更した。
- 一度目の素材は小さく、背景の柄が減っていた。原画と比較しスロット410×300、チップ156×152、SPIN204×196、フリッパー260×88へ修正した。生成外枠が厚すぎたルーレットは透明な内径を拡大して再生成した。
- 大きさを戻すと小型障害物とルーレットの間で滞留した。反発やナッジ変更だけでは解消せず、ルーレットを40px下へ、小型サイコロとチップ山を外20px・上40pxへ移動して24条件のプレイテストが通った。この配置変更で背景装飾も追従させる必要が生じた。
- 回転盤の中心は(470,890)、外枠中心は(470,875)。支柱の画像中心を軸に置くと台座がずれた。素材内の台座中心anchorY=.82を回転盤中心へ置いて修正した。このアンカーは当該素材固有。
- 影はsprites.jsで透過輪郭をぼかし、右下へ投影する。回転盤の角度ではなく固定光源に従う。
- 背景のSPIN用放射模様は旧中心付近(480,600)に残り、現在のSPIN中心(470,554)とずれた。背景の再生成時には現在配置を渡し、実画面で検証する。

主なファイル: game.js（配置・描画・ゲーム状態）、physics.js（自作物理）、sprites.js（透過素材・影）、asset-manifest.js（素材とUV範囲）、assets/（画像・生成指示）、verify.cjs、playtest.cjs。

確認コマンド: npm run check / npm test / npm run test:play。最後は12発射強度×操作あり・なしの24条件。通過は全ケースの保証ではない。実ブラウザーは http://127.0.0.1:5173/ 。ユーザーもプレイするため、UI操作が失敗したときは最新の状態を取得して再判断する。
