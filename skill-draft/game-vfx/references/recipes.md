# 効果のレシピと検証

数値は初期仮説であり、作品の速度とスケールに合わせる。

- ゴムバンパー: 接触位置の短いハイライト、法線側の少数粒子、100〜200ms程度の戻り。対象全体を点滅させ続けない。
- 金属接触: 高強度時だけ短命の細い火花。弱い接触は光だけでもよい。放出方向を法線周辺に分散する。
- チャージ: 連続値から光量や局所的な粒子密度へ変換する。毎フレームburstを発行しない。最大値で点滅を強制せず、キャンセル時も滑らかに消す。
- 成功: 小得点は控えめな表示、特別成功は専用モチーフと音楽的なタイミング。得点文字は読み取れる時間を残し、同時加点で画面を文字で埋めない。
- 球の残像: 時間または移動距離で点を追加し、過去位置を時間で減衰。停止・ワープ・リスタート時は履歴を切る。FPSに応じて残像長が変わらないようにする。
- 影: アルファから作る場合は境界のぼかし、透過の方式、暗い縁、テクスチャ端のクリップを確認する。平面上の回転と、光源に対する影の向きを混同しない。

検証: 単発と連打、暗い背景と明るい背景、低FPS、同時発生上限、pause/restart、画面サイズ変更、軽減設定。静止画で見栄えが良くても、実時間で目標を追えるか確認する。寿命後の粒子数・GPU資源が元に戻ることも調べる。
