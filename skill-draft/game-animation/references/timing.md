# 時間と補間

フレーム非依存で目標へ追従する例:

```js
const k = 1 - Math.exp(-response * dtSeconds);
value += (target - value) * k;
```

これは位置追従の一例で、物理的なバネを保証しない。慣性・減衰・質量が必要なら適切に安定したバネ積分または解析解を使う。固定刻みでも速度・加速度の単位を揃える。

固定更新の描画補間ではprevious/current状態とaccumulator比率を使う。リセット、ワープ、シーン移動で両状態を揃えないと一瞬古い場所へ伸びる。見た目の補間を当たり判定の入力へ戻さない。

タイムラインは「何秒後に音が鳴る」だけでなく、衝突・解除・完了など意味のあるイベントと結びつける。速度倍率、一時停止、キャンセルで意味が失われた音やエフェクトを遅れて発生させない。

検証ケース: 30/60/120fps相当、長いフレーム、押下中の解除、反対方向への入力、反復開始、ゲーム終了中の遷移、pause/resume、リサイズ、軽減設定。状態・支点・最終値は自動化できるが、快適なテンポは実時間で確認する。比較は同じ入力列で行う。
